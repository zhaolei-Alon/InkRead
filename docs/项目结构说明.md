# 墨读（InkRead）项目结构与调用关系说明

> 原生 iOS 小说阅读器。Swift 5 + SwiftUI + UIKit/CoreText 混合，最低支持 iOS 18.6。
> 本文档说明目录结构、每个文件的职责，以及模块之间的调用关系，便于二次开发。

---

## 一、目录结构总览

```
InkRead/                                  ← 工程根目录
├─ InkRead.xcodeproj/                     ← Xcode 工程（手写 pbxproj，源码目录自动同步）
│  ├─ project.pbxproj                     ← 工程配置：目标 InkRead、iOS 18.6、Swift 5
│  └─ xcshareddata/xcschemes/InkRead.xcscheme  ← 共享 Scheme，保证换机可直接 Run
├─ Info.plist                             ← 应用元信息：显示名“墨读”、文件共享、支持的文档类型、启动屏
└─ InkRead/                               ← 源码根（与 target 同名）
   ├─ InkReadApp.swift                    ← 程序入口：创建并注入三个全局 Store
   ├─ Assets.xcassets/                    ← 图标、强调色、启动背景色
   ├─ Resources/                          ← 首次启动自动入库的示例书
   │  ├─ Sample_StarSea.txt               ← 中文示例（5 章）
   │  └─ Sample_Lantern.epub              ← 英文示例（EPUB3，3 章）
   ├─ Models/                             ← 数据模型层（纯数据结构，无 UI、无 IO）
   │  ├─ Book.swift                       ← 书、章节、进度、书签、导入草稿
   │  └─ ReaderTheme.swift                ← 主题、字体、排版、翻页模式、设置与设置存储
   ├─ Services/                           ← 服务层（解析、存储、排版计算、系统能力）
   │  ├─ AppPaths.swift                   ← 沙盒路径常量 + JSON 编解码器
   │  ├─ LibraryStore.swift               ← 书架数据仓库：增删、正文/章节缓存、进度落盘
   │  ├─ BookmarkStore.swift              ← 书签仓库：增删查、持久化
   │  ├─ TextProcessing.swift             ← 编码探测、文本清洗、HTML/Markdown 转纯文本
   │  ├─ ChapterSplitter.swift            ← 章节标题识别与切分
   │  ├─ BookImporter.swift               ← 导入调度：按扩展名分派、装配 BookDraft
   │  ├─ EPUBImporter.swift               ← EPUB 解析：container → OPF → spine → 章节
   │  ├─ ZipReader.swift                  ← 自写 ZIP 解析（中央目录 + zlib inflate）
   │  ├─ PaginationEngine.swift           ← CoreText 分页引擎 + 分页结果磁盘缓存模型
   │  └─ NetworkMonitor.swift             ← 网络类型监听（NWPathMonitor 单例）
   ├─ Reader/                             ← 阅读页（UI + 阅读状态机 + 翻页容器）
   │  ├─ ReaderView.swift                 ← 阅读页骨架、自定义状态栏、页脚、弹层挂载
   │  ├─ ReaderViewModel.swift            ← 阅读核心状态机：章节/页码/排版/进度/书签/亮度
   │  ├─ PagePagerView.swift              ← UIKit 翻页容器：CoreText 绘制 + 手势 + GPU 动画
   │  ├─ ReaderChrome.swift               ← 呼出菜单：顶栏、底栏、进度滑杆
   │  └─ ReaderSheets.swift               ← 三个弹层：排版设置、目录、书签
   └─ Library/                            ← 书架
      └─ LibraryView.swift                ← 书架页：继续阅读、网格、导入、删除
```

## 二、分层与依赖方向

依赖是单向的，上层依赖下层，下层不感知上层：

```
┌──────────────────────────────────────────────────────────┐
│  表现层  InkReadApp / LibraryView / ReaderView            │
│          ReaderChrome / ReaderSheets                      │
└───────────────┬──────────────────────────────────────────┘
                │ 通过 @EnvironmentObject / @StateObject 注入
┌───────────────▼──────────────────────────────────────────┐
│  状态层  ReaderViewModel（阅读状态机）                     │
│          LibraryStore / BookmarkStore / ReaderSettingsStore│
└───────────────┬──────────────────────────────────────────┘
                │ 调用纯函数或读写磁盘
┌───────────────▼──────────────────────────────────────────┐
│  服务层  BookImporter → EPUBImporter → ZipReader           │
│          TextProcessing / ChapterSplitter                 │
│          PaginationEngine / NetworkMonitor                │
│          AppPaths（路径与 JSON 编解码）                     │
└───────────────┬──────────────────────────────────────────┘
                │ 只使用结构体
┌───────────────▼──────────────────────────────────────────┐
│  模型层  Book / Chapter / ReadingProgress / Bookmark       │
│          ReaderTheme / ReaderTypography / ReaderSettings   │
└──────────────────────────────────────────────────────────┘
```

关键约束：

- `Models` 只依赖 Foundation，不依赖 SwiftUI/UIKit，方便单元测试与复用。
- `Services` 不持有任何 View，可被任意界面调用。
- `ReaderViewModel` 不直接操作 UIKit 视图，只输出 `PagerModel` 数据；`PagePagerView` 只消费数据、只回传手势结果。

## 三、核心调用链路

### 1. 启动链路

```
InkReadApp（@main）
  └─ 创建 LibraryStore / ReaderSettingsStore / BookmarkStore（均为 @StateObject）
       └─ LibraryStore.init 中调用 seedSampleBooksIfNeeded()
            └─ BookImporter.makeDraft 解析 Resources 内置示例
                 └─ TextProcessing / ChapterSplitter / EPUBImporter / ZipReader
       └─ 通过 .environmentObject 注入 LibraryView
```

### 2. 导入链路（本地文件）

```
LibraryView.fileImporter（系统文件选择器）
  └─ BookImporter.importBook(url:)
       ├─ 按扩展名分派：txt / md / html / rtf → TextProcessing
       │                              epub → EPUBImporter
       │                                         └─ ZipReader（解压 + zlib）
       ├─ ChapterSplitter.split（识别“第 X 章”等标题）
       ├─ 装配 BookDraft（全文 + 章节 UTF-16 区间）
       └─ LibraryStore.add(draft:)
            └─ AppPaths 落盘：Books/<uuid>/content.txt + chapters.json
                 └─ @Published books 更新 → 书架自动刷新
```

另外 `LibraryStore.importDroppedDocuments()` 会扫描 App 的 Documents 目录（通过“文件”App 或 AirDrop 放入的文件），自动导入并删除源文件。

### 3. 阅读链路（打开一本书）

```
LibraryView → NavigationLink → ReaderView(book:)
  └─ @StateObject ReaderViewModel(book:library:settingsStore:bookmarkStore:)
       ├─ init：取章节/全文缓存、恢复进度、开启电量监听、应用亮度、订阅设置变更
       └─ body：PagerContainer（UIViewRepresentable）
            └─ makeUIView → PagePagerView
                 └─ ReaderViewModel.prepare(containerSize:) 触发首次排版
                      └─ PaginationEngine.paginate（后台队列）
                           └─ 完成后 rebuildPager() → 生成 PagerModel
                                └─ PagePagerView.apply(model) → CoreText 绘制当前页
```

### 4. 翻页链路

```
用户手势（PagePagerView 内部）
  ├─ 点击 / 拖动 → 本地动画（GPU transform，不重排）
  └─ 动画结束 → delegate.pager(_:didTurn:)
       └─ PagerContainer.Coordinator → ReaderViewModel.advance/retreat()
            ├─ 本章还有页：pageIndex ± 1 → rebuildPager()
            └─ 已到本章末尾：loadChapterDirect(相邻章)（同步、无闪烁）→ rebuildPager()
```

`PagePagerView` 在翻页前需要“下一页内容”，而下一页内容由 ViewModel 提供，因此形成 **ViewModel 出数据 → Pager 出手势 → 回调 ViewModel 改状态** 的闭环。

### 5. 设置生效链路

```
ReaderSettingsSheet（绑定 ReaderSettingsStore）
  └─ 修改 settings（@Published）
       └─ ReaderViewModel 通过 Combine 订阅 settingsStore.$settings
            ├─ 仅主题/颜色变化 → 只重建 PagerModel（重绘，不重排）
            ├─ 排版参数变化 → 0.22s 防抖后 requestLayout（后台重排）
            └─ 翻页模式变化 → 重建 PagePagerView 的轴向配置
```

### 6. 进度与书签

```
阅读位置变化 → ReaderViewModel.scheduleProgressSave()（0.5s 防抖）
  └─ LibraryStore.updateProgress(bookID:progress:) → 内存更新 + 防抖写 library.json
切后台 / 退出阅读 → saveProgress() + LibraryStore.flush()（同步落盘）

书签按钮 → ReaderViewModel.toggleBookmark()
  └─ BookmarkStore.toggle(...) → 写 bookmarks.json
  └─ 书签面板跳转 → ReaderViewModel.jumpToBookmark(_:)
```

## 四、磁盘数据结构

所有数据位于 `Application Support/InkRead/`：

```
InkRead/
├─ library.json                  ← 书列表（含每本书的阅读进度）
├─ bookmarks.json                ← 全部书签（按 bookID 过滤）
└─ Books/
   └─ <book-uuid>/
      ├─ content.txt             ← 规范化后的全书纯文本（UTF-8）
      ├─ chapters.json           ← 章节列表：标题 + UTF-16 起止偏移
      └─ layout.json             ← 分页缓存：排版签名 → 每章页切片
```

排版签名 = `字体|字号|行距|段距|页边距|首行缩进|文本区宽x高`。
签名一致时直接复用 `layout.json`，重开书秒出第一页；签名变化则自动重排并覆盖缓存。

## 五、二次开发指引

| 想改什么 | 改哪里 |
| --- | --- |
| 新增文本格式（如 DOCX） | `BookImporter` 增加分派分支 + `TextProcessing` 增加转换函数 + `Info.plist` 注册文档类型 |
| 新增主题/模板 | `ReaderTheme` 中 `ReaderTheme` 预设与 `ReaderStylePreset.all` |
| 调整分页规则（段距、缩进） | `PaginationEngine.paragraphStyle` |
| 新增手势（如双击、音量键） | `PagePagerView` 手势区 + `PagePagerDelegate` 回调 |
| 换翻页动画 | `PagePagerView.animateTurn`（当前仅 transform 位移，可换成转场/仿真） |
| 书架改版 | `LibraryView` + `LibraryStore.books` |
| 状态栏内容 | `ReaderView.ReaderStatusBar` |

性能相关的三个关键点（改动时请保持）：

1. 单页用 `PageCanvasView` + CoreText 直绘，不建 UILabel/UITextView；
2. 翻页只改 `transform`，不触发 `setNeedsDisplay`；
3. 排版全部放在后台队列，主线程只做状态赋值与 `rebuildPager()`。
