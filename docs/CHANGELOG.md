## [1.0.1] - 2026-11-21

### 修复

- **翻页后切换主题，正文区背景不实时刷新**：翻页时进场页会被设置不透明的主题背景，翻页完成后进场页转正为当前页，其残留背景会在后续切换主题时盖住容器的新背景色，表现为「上下边栏实时变色、正文区仍为旧色」。现已让当前页与进场页保持透明，正文底色统一由容器 `backgroundColor` 提供（`PagePagerView.apply` 兜底重置、`installIncoming` 进场页显式透明）。

### 文档

- 补充「主题背景双层渲染」架构说明，见 [项目结构说明.md](项目结构说明.md) 与 [README.md](../README.md)。
- 清理调试期临时日志，保持发布代码干净。

## [1.0] - 2026-11-20

### 新增

- 首个开源版本：SwiftUI + UIKit/CoreText 混合的本地小说阅读器，零第三方依赖。
- 支持 TXT / Markdown / HTML / RTF / EPUB 导入，自动编码探测与章节识别。
- 多种翻页交互、精细化排版、5 套主题 + 自定义背景色、分页磁盘缓存、书签与进度自动保存。
